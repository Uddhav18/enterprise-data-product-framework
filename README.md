# Enterprise Data Product Framework

Reusable Snowflake + dbt framework enabling rapid onboarding of enterprise data products.

## Key Features
- Layered architecture (Landing → Staging → Base → Access)
- Incremental ingestion
- RBAC and fine-grained access control
- Row-level and column-level security
- AWS Secrets Manager integration
- Airflow orchestration
- Reusable dbt macros
